Liner：关播后的主播社交匹配

关播后的“主播版 Tinder”，用 AI 把弱关系信号转成 Match、破冰文案和 LIVE Event 邀约，推动主播从认识彼此走向真实 Cohost。

100 字项目介绍

Liner 是关播后的“主播版 Tinder”。主播结束直播后，在 LIVE Center 结算页进入 AI 匹配卡池，看到基于观众重叠、互动记录、内容标签和开播时间生成的同频创作者推荐。v3.0 新增“TA 喜欢了你”分支和 LIVE Event 邀约。

赛道方向

Reshape the business value of LIVE and Gaming with AI.

推荐“可以一起播的人”，并把推荐结果变成可执行的直播邀约。

问题 · 解决方案 · 价值

Problem

成长型主播缺少低成本关系入口，弱关系信号无法自动变成 Cohost 动作。

Solution

AI Match Deck 展示高光、关系证据和匹配理由；匹配后生成破冰文案和 LIVE Event 邀约。

Business Value

提升 Match、私聊、LIVE Event 接受率、Cohost 发起率和次日开播率。

核心体验流程

  1. 1关播结算

  3. 3AI 滑卡
  4. 4Match / Super
  5. 5编辑破冰与 Event
  6. 6Received 邀约
  7. 7Chat 接受/发送 Event
