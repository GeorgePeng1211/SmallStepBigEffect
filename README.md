# Liner Hackathon Prototype v3.0

Mobile web prototype for an AI-powered TikTok LIVE creator matching experience after a streamer ends a live session.

## Deliverables

- Mobile demo: `index.html`
- One-pager: `one-pager.html`
- One-pager markdown: `one-pager.md`
- QR page: `qr.html`

## Demo Flow

LIVE Summary -> Liner Fire -> swipe deck -> Match / Super Match -> Received invite -> Chat with LIVE Event cards.

## Local Run

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

Open `http://localhost:8080/`.
